# Security

This repository is private.

## Sensitive Data

Do not commit:

- `.env` files
- API tokens or bot tokens
- database dumps
- local internal pricing source binaries, databases, backups, logs, or documents
- exported chat history that contains private details

Keep private reference material in `local-inputs/`, which is ignored by Git.

## Reporting

For security issues, create a private GitHub issue or contact the repository
owner directly.
