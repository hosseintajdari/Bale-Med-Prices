# مد اگریگیتور — تصمیم و معماری (۱۷ مهر ۱۴۰۵)

## تصمیم
ساخت «مد اگریگیتور»: موتور تجمیع قیمت دارو و مکمل که هسته‌ی مشترک قیمت/سرچ برای وب، تلگرام، بله و واتساپ میشه — دقیقاً همون هدفی که README گفته («one shared pricing and search core»). این، پروژه‌ی Bale-Med-Prices رو کامل می‌کنه.

## معماری: API-first
- `GET /search?q=` — قلب تپنده؛ بات‌های تلگرام/بله/واتساپ کلاینت نازک روی همین می‌شن
- فرانت وب جدا، دیتابیس SQLite (products / sources / prices)
- قرارداد آداپتر: هر منبع فقط `search(product) -> [PriceHit]` پیاده می‌کنه
- قانون سفت: قیمت بی‌تاریخ وارد دیتابیس نمیشه

## ترتیب منابع (دستور گرگ پیر، ۱۷ مهر ۱۴۰۵)
۱. جست‌وجوی گوگل — کشف اول
۲. پیام داروساز (payamdaroosaz.com) — منبع ثانویه
۳. قانون فارما — منبع ثالث (داده از نرم‌افزار داروخانه، با دست گرگ پیر)
۴. مکمل/آرایشی‌بهداشتی/گیاهی: داروکده (darukade.com) — راستی‌آزمایی شد: قیمت‌ها JSON-LD ساخت‌یافته، بدون لاگین، ~۲۷ هزار محصول

## نمونه‌ی مرجع
پروتوتایپ پایتون در `~/workspace/bale-med-price/` — FastAPI + فرانت فارسی + smoke test سبز (فاز صفر).

## سؤال‌های باز (نیاز به تصمیم گرگ پیر)
- مغایرت استک: ریپو TypeScript ولی پروتوتایپ Python — کدوم می‌مونه؟
- خلاصه‌ی نوشن «برداشت داده از منابع تأییدنشده» رو خارج اسکوپ گذاشته — با ترتیب منابع بالا در تناقضه؛ سند اسکوپ باید به‌روز بشه.
