# مد اگریگیتور — تصمیم و معماری (۱۷ مهر ۱۴۰۵)

## تصمیم
ساخت «مد اگریگیتور»: موتور تجمیع قیمت دارو و مکمل که هستهی مشترک قیمت/سرچ برای وب، تلگرام، بله و واتساپ میشه — دقیقاً همون هدفی که README گفته («one shared pricing and search core»). این، پروژهی Bale-Med-Prices رو کامل میکنه.

## معماری: API-first
- `GET /goods/search?q=` — قلب تپنده؛ باتهای تلگرام/بله/واتساپ کلاینت نازک روی همین میشن
- فرانت وب جدا، دیتابیس SQLite (products / sources / prices)
- قرارداد آداپتر: هر منبع فقط `search(product) -> [PriceHit]` پیاده میکنه
- قانون سفت: قیمت بیتاریخ وارد دیتابیس نمیشه

## ترتیب منابع (دستور گرگ پیر، ۱۷ مهر ۱۴۰۵)
۱. جستوجوی گوگل — کشف اول
۲. پیام داروساز (payamdaroosaz.com) — منبع ثانویه

## وضعیت پورت TypeScript (مرج شده به main)
پورت کامل شد و با موفقیت به شاخه `main` مرج شد (PR #55 و PR #58):

**فایلهای پیادهسازیشده** (`apps/api/src/services/aggregator/`):
- `types.ts` — قرارداد `SourceAdapter` + `PriceHit` (با `crawledAt` اجباری: قیمت بیتاریخ از نظر تایپی غیرممکنه) + `tomanToRial` + `RateLimitedError`
- `http.ts` — کلاینت مؤدبانه: فاصله بین درخواستها، توقف روی 429/403
- `google-discovery.ts` — کشف لینک کاندید از طریق موتور جستجو
- `torob-adapter.ts` — API عمومی ترب، بدون لاگین
- `delgarm-adapter.ts` — لیست قیمت روزانه + تطبیق فازی نام
- `aggregator-service.ts` — رجیستری آداپترها
- `aggregator.test.ts` — ۱۰ تست واحد (کاملاً سبز)

**اتصال به سرچ موجود** (نه سیستم موازی):
- `goods-service.ts`: متد `searchWithWebFallback` — اول کاتالوگ محلی، اگه خالی بود آگریگیتور وب؛ آیتمهای وب با `webSource: true` مشخصن
- `goods-controller.ts`: `GET /goods/search` کاملاً async با پشتیبانی از `await`؛ هدر `X-Search-Source: catalog | web-aggregator`؛ خطای 429 وقتی منبع محدودمون کنه

**پوشش تست و CI**:
- تمام ۱۰ تست واحد اگریگیتور در کنار سایر ۱۰۱ تست مخزن (مجموعاً ۱۱۱ تست) به صورت پایدار در GitHub Actions پاس میشوند.
