# ADR 002 استفاده مجاز و مرحله ای از قانون

**وضعیت:** پذیرفته شده  
**تاریخ:** ۲۱ مهر ۱۴۰۵  
**تصمیم گیر:** حسین تاجداری

## زمینه

داروخانه مجوز استفاده از نرم افزار قانون و مسیرهای API وابسته را دارد. هزینه جاری دسترسی برای به روزرسانی قیمت ها و قواعد مرتبط پرداخت می شود. در گذشته، محدودیت توان فنی و دسترسی به قواعد و تغییرات قیمت باعث شده بود این ظرفیت در محصول استفاده نشود؛ این محدودیت دیگر مبنای طراحی نیست.

## تصمیم

PanelPH می تواند از قانون، APIهای مجاز آن، فایل های نمونه و گردش کارهای قابل مشاهده در قانون به عنوان منبع داده و منبع شناخت فرایند استفاده کند. این استفاده می تواند شامل بررسی ساختار، دریافت به روزرسانی قیمت و قواعد در صورت وجود API مناسب، و استفاده از داده برای پیشنهاد و تطبیق کالا باشد.

## اصول اجرا

هر اتصال زنده باید منبع، تاریخ دریافت، وضعیت موفقیت و خطا را ثبت کند. داده قیمت و قواعد نسخه دار و زمان دار نگه داشته می شود. منطق PanelPH به API یا رابط قانون قفل نمی شود و پشت یک مرز منبع داده باقی می ماند. در نبود API مستند یا قابل اتکا، رابط نرم افزار به عنوان قرارداد فنی فرض نمی شود.

## مرزهای نسخه آزمایشی

مجوز استفاده از قانون، دامنه نسخه آزمایشی را به ارسال سفارش، پرداخت، تغییر موجودی، صدور سند یا تغییر داده عملیاتی گسترش نمی دهد. در نسخه نخست، استفاده زنده فقط پس از تعیین مسیر نسخه فعال، روش احراز هویت، دامنه خواندن و برنامه بازگشت انجام می شود. هیچ شناسه دسترسی یا داده محرمانه در مخزن یا گفت وگو ثبت نمی شود.

## پیامد

فایل بیمه سلامت و قانون می توانند برای ساخت داده نمونه واقع گرایانه و طراحی تطبیق اختیاری کالا استفاده شوند. اعتبار قیمت و قواعد برای عملیات واقعی فقط با تاریخ دریافت و منبع مشخص قابل ادعاست.
