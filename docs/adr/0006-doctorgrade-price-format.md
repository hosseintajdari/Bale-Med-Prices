# Doctor-grade price format and one-tap copy

Accepted (۱۷ مهر ۱۴۰۵). فرمت نمایشی: `۴۵۰٬۰۰۰ ریال (۴۵٬۰۰۰ تومان)` + منبع + تاریخ/سن قیمت. ریال واحد اصلی (رسمی)، تومان پرانتزی (محاوره). عدد لخت بدون واحد ممنوع؛ اعداد فارسی؛ جداکننده‌ی هزارگان. پیاده‌سازی واحد در `packages/domain/src/format-price.ts` تا وب و بات‌ها یکی باشند. دکمه‌ی «📋 کپی» زیر هر جواب قیمت: با تپ، قیمت در قالب کد ارسال می‌شود تا با یک تپ کپی شود.
