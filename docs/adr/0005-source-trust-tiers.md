# Source trust tiers and per-source record spec

Accepted (۱۷ مهر ۱۴۰۵, اعلام علنی گرگ پیر). «منابع تأییدشده» = پیام داروساز، قانون فارما، داروکده (مکمل/آرایشی‌بهداشتی/گیاهی). torob و delgarm آداپتر آماده دارند ولی تأییدنشده‌اند و تا تأیید گرگ پیر خارج اسکوپ‌اند. جست‌وجوی گوگل کانال کشف است نه منبع قیمت (تونل به تی‌تک نیست؛ خبر رسمی/کدال می‌دهد).

## مشخصات ثبت هر منبع (record spec)
هر منبع این فیلدها را ثبت می‌کند: `product_name` (نام همان‌طور که منبع نوشته)، `price_rial` (ریال؛ تومان ×۱۰)، `url` (لینک صفحه‌ی منبع)، `source_name`، `crawled_at` (اجباری — بی‌تاریخ ممنوع).
- **torob**: از API عمومی `api.torob.com`؛ رکوردهای بدون فروشنده (price=۰) فیلتر می‌شوند؛ بدون لاگین.
- **delgarm**: از لیست قیمت روزانه (`price_title`)؛ تاریخ لیست هم ثبت شود.
- **darukade**: از JSON-LD صفحه‌ی محصول (`price` + `availability`)؛ بدون لاگین.
- **payamdaroosaz**: از فایل‌های تغییرات قیمت؛ تاریخ فایل ثبت شود.
- **internal**: داده‌ی نرم‌افزار داروخانه با دست گرگ پیر؛ تاریخ خروجی ثبت شود.
- **google**: فقط لینک کاندید + کوئری — قیمت از گوگل ثبت نمی‌شود.
